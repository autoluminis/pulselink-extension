DTU 短信与语音使用说明

通过配套 DTU 硬件提供短信与语音通知，并在插件控制台管理设备和任务。

准备 DTU 设备

本插件需要支持对应短信与 TTS 协议的 DTU 硬件。设备主动连接插件的 TCP 监听入口，实际端口、网络与设备参数由部署者在插件控制台配置。

插件使用 GBK 编码发送短信与语音指令。请先核对设备协议与短信、语音能力，不将任意 TCP 设备视为兼容 DTU。

创建短信与语音通道

  1. 安装并启用与当前宿主版本兼容的受信任 DTU 通知插件。
  2. 按需创建并启用 sms 与 voice 通道实例，每种通道最多一个实例，渠道配置 JSON 保持 {}。
  3. 通过插件控制台配置共享网关参数，查看在线设备、设备上报日志、投递队列和历史任务。
  4. 为接收人配置对应手机联系方式，再将短信或语音通道关联通知策略。

理解任务与回执状态

每台在线 DTU 同时处理一个任务。任务尚未写入设备时连接中断，可重新进入队列；已写入后的超时或断线可能处于待确认状态，需要结合迟到 ACK 判断，不能简单视为成功或立即重发。

语音拨号、接通播放与播放结束是不同进度。通过投递 ID 关联宿主记录和插件设备日志，核对通知是否被实际处理。
