WxPusher 通知使用说明

通过插件将 PulseLink 告警发送至已配置的 WxPusher 接收者或主题。

准备服务与联系人

在 WxPusher 服务中准备应用 AppToken，并取得接收者 UID。为 PulseLink 用户添加 WxPusherUid 类型的联系方式。

WxPusher 服务官网 ↗

安装与配置通道

  1. 在 PulseLink 插件商城选择满足宿主兼容要求的 WxPusher 通知插件，或由管理员导入受信任签名 ZIP。
  2. 启用插件，创建 pulselink.wxpusher/wxpusher 通道实例。
  3. 填写应用 AppToken；按需设置文本 / HTML 内容类型和主题 topicId。
  4. 将通道加入通知策略，并确认接收人的 WxPusher UID 已配置。
{
  "appToken": "YOUR_APP_TOKEN",
  "contentType": 1,
  "topicId": null,
  "verifyPay": false,
  "url": "https://wxpusher.zjiecode.com/api/send/message"
}

contentType 为 1 时发送纯文本，为 2 时发送 HTML。配置 topicId 时也会向对应主题投递；实际服务权限和收费以服务方规则为准。

验证与排查

验证通道配置、联系人 UID、通知策略范围及网络连接，再通过投递记录核对发送结果。服务受理不等于手机已经收到消息，使用与目标版本匹配的签名插件包。
