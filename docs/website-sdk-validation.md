# 官网与通知 SDK 修复验证

日期：2026-10-16。基于 release 分支 bf84680。

## 已确认问题与修复

- 文档页 `.guide-doc a` 覆盖主按钮白字，导致 SDK/PDF 等绿色按钮文字不可见。明确主、次按钮文本颜色并增加 4.5:1 对比度回归。
- 文档目录定位未为固定页眉留空间。增加 section 的滚动偏移，并覆盖手机导航换行。
- 浏览器测试服务器使用 `/` 拼接绝对目录边界，Windows 请求全部被判为越界。使用平台分隔符，同时保持目录边界检查。
- SDK 校验和发送使用不同校验路径，校验取消未响应，静态 HTTP 客户端没有插件停止释放路径。统一校验、传递取消，插件持有并释放客户端，发送增加 10 秒边界、幂等头、禁止自动重定向；不读取服务端正文。
- 示例项目没有明确运行入口程序集名、清单模板和排除宿主 SDK 的发布引用。补齐项目设置、plugin.json 和 marketplace.json 输入模板。
- 开发资料缺少从下载到交付验收的完整步骤。增加独立指导书、在线操作步骤、回执与运行时说明、签名命令、升级回滚及排错。
- 打包器未核对冻结契约，缺少下载包内容回归。增加 21 个契约文件校验、换行规范化、打包后内容及可重复构建检查，CI 从 ZIP 运行示例回归。
- Linux CI 发现 Windows 与 Linux 生成 ZIP 字节不一致；固定 ZIP 平台元数据、无压缩存储与按 POSIX 字符串排序的文件顺序。Windows Path 默认排序不区分大小写，Linux 区分；修正后本地包 SHA-256 与 Linux 日志中的包摘要一致（85bbe9a8b39050f4ab3ce4936e9f6e309ededa7ab60cd0006fb6b8f9a4afef1a），并增加条目顺序回归，保留原有字节一致性检查。

## 本地验证结果

- 官网 `npm test --prefix website-tests`：5/5 通过。包括所有 HTML 本地资源/链接/锚点、320–1920 像素首页布局、桌面/手机文档、导航和翻屏、安装/OTA 下载、失败清空链接、目录签名及错误、弹窗键盘操作、PDF 和 SDK 下载。
- 下载包 `python sdk/tools/test-notification-sdk.py`：3/3 通过，核对 SHA-256、文件内容、冻结契约及重复生成一致性。
- 从正式 SDK ZIP 解压后构建示例：0 警告、0 错误；确认示例输出没有 PulseLink.Plugin.Abstractions.dll。
- 从解压目录运行 `dotnet run --project tests/GenericWebhook.Tests.csproj -c Release`：37 项检查通过，覆盖无效配置、载荷、去重头、4xx/429/5xx/重定向、发送前及发送中取消、10 秒超时与重复停止资源释放。
- 将 SDK 21 个契约源文件与当前本地 PulseLink 宿主公共契约逐项比较：无差异。未改变公共接口及契约版本。
- 已生成并检查 1440 和 320 像素文档页面截图，主下载按钮文字恢复可见。
