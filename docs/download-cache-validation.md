# 下载地址缓存与限流回退

日期：2026-10-16。

## 原因与修复

首次安装 EXE 只通过访客浏览器查询 GitHub Releases API 发现；匿名 API 403/429 或临时网络错误会隐藏下载按钮。旧实现只有 OTA 索引回退，缺少安装包地址快照和跨刷新缓存。

- 新增官网同域 download-snapshot.json，首次访问即可使用，不依赖此前成功查询；缓存保存官方下载元数据，安装文件仍由 GitHub Release 提供。
- 新增浏览器最近成功记录，使用同一仓库、通道、平台、版本及资产 URL 校验。存储被禁用或记录损坏不会中断页面。
- 在在线查询进行中和临时失败时保留可用缓存链接，标注记录时间、可能不是最新版本及重新检查入口。在线查询确认包不存在时清除旧链接；非法响应或登录失败不借缓存绕过检查。
- Pages 部署时使用受限 Actions 令牌刷新公开快照，页面不包含令牌；正式 OTA 发布成功后触发官网部署，避免仅靠浏览器请求更新版本资料。
